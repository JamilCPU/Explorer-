# Explorer

An early skeleton for a text-based Java exploration game in which a player moves across a grid board containing roads and trees. Only a handful of empty or near-empty classes were written (`Board`, `Player`, `Road`, `Tree` and a `gameObject` interface) and there is no entry point, so the game was never completed.

## Stack

- Java (plain source files, no build tool)

## Status

Abandoned at the class-skeleton stage; there is nothing to run.
